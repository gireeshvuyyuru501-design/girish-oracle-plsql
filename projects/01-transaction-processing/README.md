# Transaction Processing & Reporting

**Portfolio demonstration — not employer/client production code.**

This project shows a compact Oracle PL/SQL design for transaction processing and reporting.

## What it demonstrates
- Oracle tables, constraints, indexes and sequences
- PL/SQL package specification and body
- Stored procedure and function design
- Exception handling
- Trigger-based audit logging
- Reporting SQL with CTEs and analytical functions

## Files
- `schema.sql`
- `order_pkg.sql`
- `audit_trigger.sql`
- `reporting_queries.sql`
