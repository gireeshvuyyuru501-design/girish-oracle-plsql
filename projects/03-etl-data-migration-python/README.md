# ETL, Data Migration & Python API

**Portfolio demonstration — not employer/client production code.**

This project demonstrates a staging-to-target migration pattern with data validation, reconciliation and a minimal Python/FastAPI API example.

## What it demonstrates
- Staging and target table design
- PL/SQL ETL package
- Data cleansing and validation
- MERGE-based upsert
- Reconciliation SQL
- Python/FastAPI database integration
